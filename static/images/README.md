# Immagini per il sito Giardiniere Pro

## Immagini da aggiungere:

1. **gardener-hero.jpg** - Immagine principale del giardiniere professionista (dimensioni consigliate: 1200x800px)
2. **placeholder-project.jpg** - Immagine placeholder per i progetti (dimensioni consigliate: 800x600px)
3. **logo.png** - Logo del sito (dimensioni consigliate: 200x200px)

## Cartelle per i progetti:
- `media/projects/` - Immagini principali dei progetti
- `media/projects/before/` - Immagini "prima" del lavoro
- `media/projects/after/` - Immagini "dopo" del lavoro

## Note:
- Le immagini devono essere in formato JPG o PNG
- Comprimere le immagini per ottimizzare i tempi di caricamento
- Utilizzare nomi descrittivi per i file
- Rispettare i diritti d'autore delle immagini
